## 我怎么做事

- **端到端**：需求进来，能跑的系统出去 —— 产品、后端、前端、部署一条龙。
- **Agent 基础设施**：编排、协议（ACP / MCP / iLink）、以及让 Agent 出现在用户已经在的地方的远程入口。
- **交付优先**：先做能解决真问题的最小东西，然后只改客户抱怨的部分。不是反过来。

背景：某软件公司工程负责人，在做计算机视觉 + 硬件。此前与 **GE**、**中国电信**、**满帮** 的团队合作过。
