## 在做的事

围绕 **AI 时代个体生产力** 做产品与工具：

- 解决"我应该做什么、谁来做、做完怎么验收"——AI Agent 调度
- 解决"AI 工具很多但我没法一站式用"——视频/内容创作工作流
- 解决"做出来怎么沉淀、怎么分享"——内容展示与协作

工程实现集中在 **Go / TypeScript / Electron** 三个栈，覆盖命令行、桌面应用、Web 三类形态。
